# Análise de Ortologia (RBH) e Filogenia

Este repositório contém o pipeline completo e os resultados de uma análise de ortologia em larga escala e reconstrução filogenética baseada em 5.897 sequências de proteínas. O objetivo central é mapear genes ortólogos reais (via Reciprocal Best Hits - RBH) e reconstruir a história evolutiva dos organismos com alto rigor estatístico.
​Metodologia e Pipeline
​Identificação de Ortologia (RBH): Mapeamento rigoroso de pares ortólogos entre os proteomas para garantir confiabilidade funcional e evolutiva.
​Alinhamento Múltiplo (MSA): Processamento e alinhamento de alta performance das sequências.
​Filogenia por Máxima Verossimilhança (IQ-TREE): Utilização do software IQ-TREE para modelagem evolutiva e geração da árvore filogenética de máxima verossimilhança (.treefile).
​Resultados e Visualização
​Árvore Filogenética Global: A topologia gerada evidencia a divergência genética e a relação hierárquica entre os clados analisados.
​Exploração Interativa (iTOL): O projeto conta com suporte à visualização interativa avançada para busca de acessos específicos (WP_..., NP_...).
